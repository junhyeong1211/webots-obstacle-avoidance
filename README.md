

# PROJECT 01 | Webots Obstacle Avoidance

**Webots R2025a · C++ · e-puck · Reactive Control**  
**진행 기간:** 2026-10-11 ~ 2026-10-14  
**상태:** 장애물 회피 MVP 구현 및 기본 성능 검증 완료 / 시연 영상 추가 예정

## 1. 프로젝트 소개

Webots의 e-puck 차동구동 로봇을 C++로 제어하여, 적외선 근접 센서 8개의 입력에 따라 장애물을 자율 회피하는 프로젝트입니다. 차동구동 운동학 계산, 개방루프 회전 실험, 엔코더 기반 오도메트리와 실제 자세 비교를 거쳐, 센서 기반 반응형 제어기를 구현하고 여러 환경에서 시험했습니다.

## 3. 제어 알고리즘

`Sensor → Perception → Decision → Actuation`를 32 ms 제어 주기로 반복합니다.

1. `ps0`~`ps7` 센서값을 수집합니다.
2. 센서별 감지 시작 기준 `110`, 해제 기준 `90`으로 히스테리시스를 적용합니다.
3. 오른쪽(`ps0`~`ps2`)과 왼쪽(`ps5`~`ps7`)의 감지 신호를 각각 합산합니다.
4. 양쪽 신호가 0이면 전진하고, 한쪽 신호가 더 크면 반대 방향으로 회전합니다. 양쪽 신호가 같고 0보다 크면 임시 규칙에 따라 좌회전합니다.
5. 상태에 따라 바퀴의 목표 각속도(rad/s)를 명령합니다.

| 상태 | 왼쪽 모터 | 오른쪽 모터 |
|---|---:|---:|
| `FORWARD` | +3.0 | +3.0 |
| `TURN_LEFT` | −2.0 | +2.0 |
| `TURN_RIGHT` | +2.0 | −2.0 |

감지 임계값과 모터 속도는 이번 시뮬레이션에서 사용한 설정값으로, 물리적 안전거리나 최적값을 의미하지 않습니다.

## 4. 시험 결과

### 장애물 회피

| 실험 | 환경 | 결과 |
|---|---|---|
| A | 단일 장애물 1개 | 60초 무충돌, 10초 이상 정체 없음 (1회) |
| B | 다중 장애물 3개 | 60초 무충돌, 10초 이상 정체 없음 (1회) |
| C | U자형 막다른 공간 | 열린 출구로 탈출 확인 |

### U자형 탈출 반복 실험 (2026-10-14)

각 초기 방향에서 3회씩, 총 9회 실행했습니다. **탈출 성공 9/9회(관찰된 성공률 100%), 충돌 0회**입니다.

| 초기 방향 | 탈출 시간 3회 (초) | 평균 (초) | 표본 표준편차 (초) |
|---|---|---:|---:|
| 0° | 11.776, 12.288, 11.776 | **11.947** | 0.296 |
| +45° | 13.312, 13.312, 13.312 | **13.312** | 0.000* |
| −45° | 12.800, 12.800, 12.800 | **12.800** | 0.000* |
| **전체 (9회)** | — | **12.686** | 0.615† |

\* 관측값이 동일하다는 뜻이며 실제 시간 변동이 없다는 증거는 아닙니다.  
† 전체 표준편차는 초기 방향이 다른 조건들을 섞은 값으로, 동일 조건의 반복 정밀도로 해석하지 않습니다.

**시간 측정 주의:** 제출된 탈출 시간은 모두 `0.512 s`의 배수입니다. Console의 약 0.512초 출력 시각을 기준으로 기록했을 가능성이 있으므로, 실제 탈출 시점을 제어 주기(32 ms) 수준으로 직접 측정한 결과라고 표현하지 않습니다. 자세한 원시 데이터는 [`data/u_turn_trials.csv`](data/u_turn_trials.csv)에 있습니다.

### DAY 02 — 회전각 검증 (참고)

| 조건 | 엔코더 기반 회전각 추정 | Webots 몸체 자세 변화 |
|---|---:|---:|
| 좌/우 ±3.0 rad/s | 약 −93.01° | 약 −85.45° |
| 좌/우 ±1.5 rad/s | 약 −90.78° | 약 −83.22° |

엔코더는 바퀴 회전량을 측정합니다. 몸체 회전각은 바퀴 미끄러짐, 유효 기구 파라미터, 물리 접촉 조건 등으로 추정값과 다를 수 있으며 정확한 원인은 별도로 확정하지 않았습니다.

## 6. 실행 방법

1. Webots R2025a에서 `worlds/obstacle_avoidance.wbt` 또는 테스트용 `.wbt` World 파일을 엽니다.
2. e-puck의 `controller`가 `epuck_cpp`인지 확인합니다.
3. `controllers/epuck_cpp/epuck_cpp.cpp`를 Webots에서 빌드합니다.
4. 초기 자세가 저장된 World를 Reload한 뒤 Real-time으로 실행합니다.
5. 로봇이 이동한 **시뮬레이션 상태를 초기 World에 저장하지 않도록** 주의합니다.

Webots 모델의 `EXTERNPROTO` 참조 때문에 최초 실행 시 외부 리소스를 가져오려 할 수 있습니다.

## 7. 프로젝트 한계 및 후속 과제

- 제한된 장애물 배치, 초기 방향 3종, 각 3회에서 얻은 결과입니다.
- 센서 반사 신호는 거리(cm)가 아니며 장애물의 재질·각도와 센서 특성에 영향을 받습니다.
- 임계값 및 바퀴 속도는 최적화하지 않았습니다.
- 지도 기반 위치 추정·경로 계획·SLAM은 구현하지 않았습니다.
- 시간 측정 해상도를 개선하려면 Supervisor 또는 별도 위치 추적 방식으로 출구 통과 순간을 기록해야 합니다.

**결론:** 특정 Webots 테스트 환경에서 동작하는 반응형 장애물 회피 MVP를 구현하고 기초 반복 실험으로 검증했습니다. 실제 하드웨어에서도 동일한 성능이 나타난다는 주장은 하지 않습니다.
