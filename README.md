# Webots Differential Drive Robot

**C++ 기반 차동구동 로봇 제어 및 자율 장애물 회피 프로젝트**

**개발 기간:** 2026.10.11 ~ 진행 중

## 1. 프로젝트 소개

Webots 시뮬레이션 환경에서 e-puck 로봇의 센서와 모터를 C++로 제어하는 로보틱스 학습 프로젝트입니다.

차동구동 운동학을 이론적으로 분석하고, 엔코더를 이용한 회전각 추정과 실제 시뮬레이션 결과를 비교했습니다.

이후 8개의 적외선 근접 센서, 히스테리시스, 상태 기반 제어 알고리즘을 이용한 자율 장애물 회피 기능을 구현했습니다.

## 5. 핵심 제어 알고리즘

### Sensor → Perception → Decision → Actuation

1. 적외선 센서 `ps0~ps7`에서 측정값 수집
2. 히스테리시스 조건으로 장애물 감지 상태 결정
3. 오른쪽 센서 `ps0~ps2`, 왼쪽 센서 `ps5~ps7`의 감지 신호 합산
4. 좌우 신호 크기를 비교해 이동 방향 결정
5. 로봇의 상태에 따라 좌우 모터 각속도 설정
6. 매 제어 주기마다 반복

**초기 제어 파라미터**

| 파라미터 | 설정값 |
|---|---|
| 장애물 감지 시작 | 110 이상 |
| 장애물 감지 해제 | 90 이하 |
| 전진 | 좌/우 +3.0 rad/s |
| 좌회전 | 좌 −2.0 / 우 +2.0 rad/s |
| 우회전 | 좌 +2.0 / 우 −2.0 rad/s |
| 양쪽 신호 동일 | 좌회전 (임시 탈출 규칙) |

센서 임계값과 속도는 현재 World에서 동작을 확인한 초기 실험값이며 최적화된 파라미터는 아닙니다.

## 6. 실험 결과

### Day 02 — 목표 90° 회전

| 항목 | 고속 실험 A | 저속 실험 B |
|---|---:|---:|
| 모터 속도 | ±3.0 rad/s | ±1.5 rad/s |
| 엔코더 기반 추정 회전각 | 93.01° | 90.78° |
| 실제 몸체 회전각 | 85.45° | 83.22° |

엔코더 기반 운동학 추정값과 몸체의 실제 자세 변화 사이에 차이가 나타났습니다. 기구 모델 오차 및 접촉 조건 등이 가능한 원인으로 남아 있습니다.

### Day 03 — 장애물 회피

**테스트 환경:** RectangleArena 및 e-puck

**관찰 결과**
- 60초간 자율주행 성공
- 육안 관찰 기준 장애물 충돌 0회
- 장애물 접근 시 회전 동작 확인
- 장애물 감지 해제 후 직진 복귀 확인

현재 결과는 단일 실행에서 관찰한 성과이며, 다양한 장애물 배치에서 반복적인 성능 검증은 아직 진행하지 않았습니다.
